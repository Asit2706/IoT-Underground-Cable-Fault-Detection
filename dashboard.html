ℹ️ About This System
Project information and component specifications

⚡ IoT-Based Underground Cable Fault Detection System

This system detects and locates faults in underground electrical cables using a voltage divider network simulated by resistors. When a fault occurs (cable cut or damage), the voltage at that segment drops below the calibrated baseline, triggering an alert on the OLED display and cloud dashboard.

🔧 Component Specifications

MicrocontrollerESP32 Dev Module
DisplayOLED SSD1306 128×64 (I2C)
Cable Simulation4 × Resistors in series
ADC Resolution12-bit (0–4095)
Supply Voltage3.3V
Cloud PlatformFirebase Realtime Database
Update IntervalEvery 3 seconds
Detection MethodVoltage Drop (Murray Loop Principle)
